# RouterMate (v2.0)

Smart Wi-Fi & router administration dashboard with real-time bandwidth monitoring, device management, hardware access controls, and AI diagnostics.

## Features

- **Real-Time Bandwidth Stream**: Live 2-minute download/upload throughput charts.
- **Device Management**: Instant device discovery, one-tap block/unblock, bandwidth limiters, and custom renaming.
- **Hardware Access Control (ACL)**: Blacklist (Deny) and Whitelist (Pass) filtering for hardware antenna protection.
- **AI Diagnostics**: AI Router Assistant with automated latency and congestion audits, and device intelligence.
- **ISP Emergency Quick-Dial**: One-tap phone dialer, WhatsApp direct chat, bKash payments, and IMO support.
- **Dual-Language**: Complete support for English and Bengali (বাংলা).
- **Modern Vector Branding**: Premium glowing cyber-neon logo with responsive design across desktop and mobile.

## Development

```bash
npm install
npm run dev
```

The app will start on `http://0.0.0.0:3000`.
